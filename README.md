# Smart Utility Toolkit 🚀

## Project Description

Smart Utility Toolkit is a simple Node.js project that demonstrates important Node.js concepts and built-in modules.

This project includes:
- A command-line calculator
- Custom modules
- A basic HTTP server
- A file manager
- A random dice generator
